# TV-One – Releases

Fertige Installationsdateien (APK) der App **TV-One** für Android TV / Google TV.

## Installation auf dem TV
1. App **«Downloader»** aus dem Store installieren und «Unbekannte Apps installieren» erlauben.
2. In Downloader diese Adresse eingeben:
   `https://github.com/Swisson-CH/TV-One-Releases/releases/latest`
3. Die Datei `tv-one-….apk` herunterladen und installieren.

Bereits installiert? In TV-One unter **Einstellungen → App-Update** aktualisieren.
